# Personal Portfolio

A simple personal portfolio website created to showcase my **education, skills, projects, and contact details**.

### What it Contains

* Home and introduction
* About Me
* Education
* Skills
* Projects
* Contact section


### How It Was Built

* **HTML** – Used to create the structure and sections.
* **CSS** – Used for styling, layout, responsive design, and dark mode.
* **JavaScript** – Used to add interactivity such as the theme button and "Say Hello" message.

### Technologies Used

HTML | CSS | JavaScript
